# JavaScript Fundamentals: From Requirement to Deep Understanding

This track is built specifically for your midterm handout.

Goal: learn only what is required, then go one layer deeper so you understand why each line works.

## How This Track Is Structured

Every lesson uses 3 layers:

1. Layer 1: What you need to pass the requirement
2. Layer 2: Why that code works
3. Layer 3: Deeper mental model to avoid future bugs

## Study Rule

If any line is confusing:

1. Ask: What value goes in?
2. Ask: What value comes out?
3. Ask: Which object owns this method?
4. Print values with console.log.

Most beginner bugs disappear when those four checks are done consistently.
